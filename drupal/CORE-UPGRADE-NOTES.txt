Actualización Drupal 10.x (mayo 2026)
=====================================

Versión final core: 10.6.8 (core-recommended, scaffold, core-dev alineados).
Drush: 13.7.3.

Snapshot DDEV previo al cambio (restauración local):
  ddev snapshot restore next-starterkit-pre-d10-core-2026-05-13

Parches Composer:
  - Eliminado el parche drupal/core #3002532 (language / recipe): el cambio ya está incluido en ConfigurableLanguageManager::updateLockedLanguageWeights() en 10.6.8.
  - Eliminado el parche drupal/decoupled_router #3111456 (oct 2024): el código equivalente viene en decoupled_router 2.0.6 upstream; el parche ya no aplica y no es necesario.
  - Restantes: subrequests, paragraphs, graphql (GitHub), webform_rest.

Actualización masiva módulos contrib (composer update drupal/*):
  - Incluye entre otros: admin_toolbar 3.6.3, graphql 4.14, graphql_compose 2.4.1, next 2.1.0, consumers 1.24, pathauto 1.15, redirect 1.13, elasticsearch client 8.19, etc.
  - Tras next 2.1: revisar CORS si el front hace peticiones desde el navegador (next_post_update_remove_automatic_cors); ver CORS.md del módulo next.

Base de datos:
  - Ejecutado system_update_10600 (equivalente a actualización de rama 11.x documentada en core).

Deuda / preparación Drupal 11:
  - Perfil basic (web/profiles/custom/basic): core_version_requirement ^9 y dependencias legacy (ckeditor, bartik, seven); revisar antes de D11.
  - Módulos custom: ampliar core_version_requirement a ^10 || ^11 cuando se aborde D11.
  - PHP: proyecto >=8.2; Drupal 11 requerirá revisar mínimo (típicamente 8.3+). DDEV local ya usa PHP 8.3.
  - composer audit: webonyx/graphql-php 14.x tiene advisories PKSA; subir a graphql-php 15.x requiere que drupal/graphql lo permita en una release futura, o revisar config audit en Composer.

Rama sugerida para estos cambios: drupal-10-latest
